What each module does

angles.py

Generates the AI prompt file you paste into Claude to get video angle ideas. Takes the breakout clusters and formats them as a research brief.

After running option 6, open angles_prompt.md and paste it into Claude to get 15 specific angle ideas for the niche.

api_keys.py

Manages your 12 YouTube API keys — loads them from .env, chains them so you don't burn one out, and reserves the last two for topic grading.

You don't call this directly. It runs in the background every time the engine hits YouTube.

baseline.py

Computes the niche's own percentile anchors — what's a typical view count, what's a typical upload rate. Everything else compares against these numbers.

You never call this directly. It runs automatically when you build or load a niche.

calendars.py

Produces a publishing calendar based on when the winning videos in a niche were uploaded. Tells you which days and times have historically produced the most breakouts.

After running option 6, open the timing/ folder to see the best days and hour-blocks to publish.

calibration.py

Holds the calibrated thresholds for market-size and spread labels — what counts as a 'large' market, what makes a spread 'gentle' vs 'brutal'. Separately calibrated at 30d, 90d, and 365d from real niche data.

When you see 'gentle for large markets' on a niche summary, that label came from this module.

channel.py

Fetches and analyses a single channel's full video catalogue — cadence, trajectory, breakout rate, title patterns, tags. Also computes the diff between two channels.

Option 4: tear down a channel you admire to see exactly how they operate. Option 5: compare two channels side by side to see where they diverge.

collector.py

The part that actually talks to YouTube. Runs the searches, downloads video metadata, handles key rotation, retries failed requests, and saves everything to disk.

Option 1. Everything you can explore for free was collected by this module at some point.

compare.py

Loads all your built niches and lines them up in one table so you can compare market size, spread, and scores at a glance.

Option 11: 'I have 10 niches built. Which one has the best spread for a newcomer?' — one command, one table.

config.py

All the tunable numbers in one place — minimum videos per cluster, breakout score weights, spread calibration thresholds, bootstrap resamples. Change a number here and it flows everywhere that uses it.

If you want to see more clusters in a breakout report, raise CLUSTER_MAX here.

coverage.py

Checks how much of the niche's content actually got picked up by the cluster analysis. Warns you when a large share of videos don't cluster — which usually means contamination or a very fragmented niche.

When a breakout report says '32% unmatched — possible contamination', that warning came from this module.

crossniche.py

Grades a niche against all your other niches rather than against itself. This is what makes option 8 useful — without it, every niche would score identically on demand and supply.

Option 8: 'Is ancient_history a strong niche or a weak one compared to the 9 others I've built?' — this module does the pooled comparison.

dashboard.py

Produces the market dashboard export — a one-page summary of a niche's key numbers formatted for quick review.

After running option 6, open the market/ folder for the dashboard.

discover.py

The main analysis engine. Scores every video as a breakout candidate, groups them into topic clusters, and writes everything out — the research MD, the discovery MD, the clusters CSV, the JSON, the video table.

Option 6. This is the module you interact with most, even if you never open it.

grader.py

Scores a single topic or niche across the three pillars — demand, supply, momentum — and combines them into an opportunity score.

Option 2: 'Is there a market for a video about Excel automation?' — grader runs and returns a score with pillar breakdown.

insights.py

Derives summary statistics from a video dataset — lifecycle, evergreen ratio, engagement patterns, creator-size distribution. Written to insights.json alongside every build.

When a niche summary tells you '72% of content is evergreen', that reading came from this module.

main.py

The entry point — the numbered menu you interact with. Reads your input, calls the right module, and handles the interactive flows like picking a niche or a window.

This is what runs when you type 'py main.py'.

metrics.py

Computes per-video derived metrics from the raw API data — views_per_hour, outlier_ratio, breakout_velocity, engagement_rate. These are the numbers every other module reasons about.

You never call this directly. It runs as part of option 1 when building a niche.

paths.py

Handles all the file path logic — where datasets live, where exports go, how to name files with niche and window so nothing overwrites anything else.

If you ever wonder why a file is named 'ancient_history_365d_breakout.csv', the naming convention is enforced here.

quota_tracker.py

Tracks how many YouTube API units you've spent this session, per key. Shows the bar at the end of every run so you can see what you have left.

The 'Quota used: 22,497 / 120,000 units' line printed after every build comes from this module.

report.py

Formats and prints results to the terminal — niche summaries, grade reports, quota bars. Also the module that adds calibration warnings when a number shouldn't be fully trusted.

The formatted output you see in the terminal after running option 7 or 8 is this module rendering the numbers.

seo.py

Analyses which title words, hashtags, and tags are most associated with breakout videos. Uses a Wilson-score-corrected lift ranking so small-sample noise doesn't dominate.

After option 6, open packaging/seo.md to see which title words and tags the winners used more than average.

shorts.py

Analyses the Shorts that were filtered out of the main dataset. Finds which topics are busy in short form but thin in long-form.

After option 6, open shorts/shorts.md to see if any Shorts-heavy topics are underserved in full-length format.

signals.py

Gathers demand signals from outside YouTube — Google autocomplete (what people are searching) and Reddit (what communities are discussing). Produces the intent gap report.

Option 3: 'What are people searching that nobody has covered yet in this niche?' — this module finds those gaps.

statistics.py

Computes and saves the summary statistics for a niche dataset — percentiles, medians, channel-size breakdown. The numbers that appear in every niche summary.

The 'median views: 4,200' line in a niche snapshot comes from the statistics.csv this module writes.

thumbnail_sheet.py

Downloads thumbnails for the top breakout videos and tiles them into a contact sheet image for visual study.

Option 9: 'Show me what the winning thumbnails in this niche actually look like' — contact sheet of 20 images.

timing.py

Analyses publish-time patterns — which hour blocks and day-of-week combinations produced the most breakouts. Uses shrinkage and bootstrap CIs so thin time slots don't look falsely confident.

After option 6, open timing/ to see the best hour blocks to publish in this niche.

trends.py

Compares two builds of the same niche taken at different times to measure actual change — views gained, new creators, rising and falling topics.

Option 10: 'Has this niche actually grown since I last built it?' — trends does the before/after comparison.

verdict.py

The composite scoring system — combines Entry, Durability, Reliability, Reward, and Effort into one score per niche, then ranks and compares them. Produces the verdict HTML report.

Option 11 → verdict HTML: 'Of my 10 niches, which should I actually enter?' — verdict scores and ranks them on the five dimensions.

End-to-end workflows

Find what to make

You have a niche. You need ideas that are genuinely under-served, not just ideas.

1build → 6discover → breakout_research.md → paste into Claude → 2grade the best 2-3

The main loop — everything else supports it. Don't skip the grading step. An angle that reads beautifully can still sit in a saturated corner, and 1,000 units is cheap insurance against a week of wasted production.

13,000 units to build · ~1,000 per topic graded

Validate one idea

You already know what you want to make. Is the market actually there?

2grade topic against niche

Read the demand-minus-supply imbalance, not the headline score. Demand well above supply is the signal. Momentum tells you whether you're early or late.

~1,000 units · needs a niche built first

Decide which niche to enter

You have several niches built. Which one should you actually commit to?

11compare → _verdict.html

Option 11 shows the table. At the end it offers a scored verdict — say yes. It measures whether a small channel ever wins here, whether the catalogue compounds, how concentrated the outcomes are, and what a hit is worth. No quota — reads videos.csv from disk.

Free · reads videos.csv from disk

Cross-niche topic research

You want title ideas that borrow proven vocabulary from adjacent niches, not just your main one.

6discover main niche → breakout_discovery.md → repeat for 1-2 crossover niches → paste all 3 + your prompt into Claude

The discovery MD is lean on purpose — 6-8KB per file so pasting three together doesn't blow the context window. Your standalone prompt does the ranking and title generation; the files just carry the cluster data.

Free · all three reads are from disk

Clone a channel you admire

One creator is doing exactly what you want to do. What exactly are they doing?

4teardown → teardown.md → thumbnails/

Cadence, growth trajectory, their own breakouts, title templates, tags and thumbnails. Costs ~13 units because a catalogue comes from the uploads playlist (1 unit per 50) rather than search (100 per call). Format transfers; specific videos don't.

~13 units for a 300-video channel

Compare two channels directly

How do two creators in the same space actually differ — who's performing better, and why?

5compare two channels → diff.md → diff.json

Performance, cadence, format, trajectory, title language overlap and tag overlap — all in one diff. Costs about 26 units total (13 per channel catalogue).

~26 units total

Learn how to package it

Topic decided. Now: how do the winners title and thumbnail it?

6discover → packaging/seo.md → 9contact sheet

Tag lift, title word lift, hashtag patterns. Lift is correlational — it shows what winners did, not what caused the winning.

Free after the build

Research keywords

What do people actually type into the search box?

3autocomplete → intent_gaps.md → paste into Claude for triage

Google autocomplete harvest — what gets suggested tells you what's being searched. The intent gap report crosses this against your niche to find what's searched but not covered. Matching is lexical, so triage with AI before acting.

Free · no YouTube quota

Find what's coming

Cover something before the wave reaches YouTube.

3Reddit signals → signals/reddit_signals.md

Terms climbing on Reddit but thin on YouTube. Treat these as leads to check, not forecasts — the idea that social chatter reliably precedes YouTube is widely repeated and never actually demonstrated.

Free · no YouTube quota

Compare at a shorter window

You have 365d builds. You want to see what the last 90 days looks like across all of them at once.

13slice library to 90d → 11compare at 90d

Slicing is free — it re-filters the data you already paid for. Option 13 does all your niches in one go. Then option 11 will ask which window you want — type 90 (not 90d) and it compares the slices.

Free · zero API calls

See what actually moved

Is this niche going anywhere since you last looked?

10trends → trends/since_last_build.md

The only measured demand figure the engine produces. Everywhere else views_per_hour is a lifetime average — two snapshots give actual views gained, separating still being watched from finished months ago. Needs two builds of the same niche, days apart.

Free · reads the history/ folder

See which themes actually last

Is this format durable, or was it a moment?

6discover → breakouts/by_era.md

Breakouts split into 0-90d / 90-180d / 180-365d, each ranked against its own contemporaries. A theme appearing in all three eras is a format; one appearing only in the newest is a news cycle.

Free · slices the build you already have

Find a repeatable format

A series, not a one-off.

6discover → breakouts/breakout_clusters.csv → sort by unique_channels

A cluster where seven or more separate channels succeeded is a format, not a fluke. That's the difference between one good video and a content engine.

Free after the build

What it can't do

Worth knowing before you go looking for these.

Tell you whether your video will work
It never sees your channel. Every number describes the market, not your odds in it.
Judge whether a video is on-topic
There's no topical relevance filter, deliberately. Occasional off-topic leaks are the price of not silently dropping things that only look irrelevant. Run the cleaning workflow on any niche before treating its numbers as calibration data.
Measure current demand from one build
A single snapshot cannot separate a video still climbing from one that stopped a year ago — views_per_hour is a lifetime average. Option 10 fixes this, but only once you have two builds of the same niche to compare.
Measure search demand in the scoring
Scores are built from how existing videos performed. A topic nobody has covered looks identical to a topic nobody wants. Option 3 gets close from the outside, but it doesn't feed the scoring yet.
See why a video worked
Click-through rate, average view duration, retention and traffic sources are private analytics. No public API exposes them at any price, for any channel. Everything here is inference from outside.
Validate the Reliability score
Reliability measures outcome concentration — how narrow the gap between a decent and a great video is. That's a reasonable proxy for predictability, but it hasn't been checked against real channel outcomes. Treat it as a structured heuristic until you have your own data to compare against.
